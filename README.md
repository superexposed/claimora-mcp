# Claimora

Claimora is a structured scientific and legal claim graph. Query claims, evidence, contradictions, and innovation flags.

## Endpoint

`https://claimora.si/mcp`

## Pricing

10 free calls per day. Paid calls use the header `X-Claimora-Paid-Token`.

Fund an account at [https://claimora.si/credits](https://claimora.si/credits).
